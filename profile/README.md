Tethr is a free, open-source service that keeps track of what you watch, in whichever player you watch it. It's compatible with the Trakt API, so an app that already supports it can switch by changing its server address. It's early, and not open for sign-ups yet.

- [tethr](https://github.com/tethrtv/tethr): the server and the website at [tethr.tv](https://tethr.tv)
- [tethr-swift](https://github.com/tethrtv/tethr-swift): a Swift package for apps on iOS, tvOS, macOS and visionOS
- [jellyfin-plugin](https://github.com/tethrtv/jellyfin-plugin): logs what everyone on a Jellyfin server watches

What's being worked on is on the [project board](https://github.com/orgs/tethrtv/projects/1).
